# ✊✋✌️ Rock Paper Scissors Game

A fun and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. The game allows users to play against the computer with real-time score tracking and instant game results.

## 🚀 Features

- Play against the computer
- Random computer move generation
- Real-time score tracking
- Win, lose, and draw detection
- Interactive game messages
- Responsive design for desktop, tablet, and mobile devices
- Clean and user-friendly interface

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)

## 🧠 Problem Solving Approach

- Implemented random move generation for the computer using JavaScript.
- Applied game logic to determine the winner for every round.
- Updated scores dynamically without reloading the page.
- Used DOM manipulation to display game results instantly.
- Designed a responsive layout for a smooth experience across different screen sizes.
